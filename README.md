# Eksamensmateriale – histologi

## Ny versjon: oppgave, bilder og sensur samlet

[Last ned PDF-en med oppgave og tilhørende bilder, etterfulgt av original sensorveiledning](dokumenter/Histologi_oppgave_bilder_sensur.pdf).

Denne versjonen samler 130 oppgaver fra 30 eksamenssett. Sensorveiledningen følger hver oppgave, før neste oppgave begynner. Lange besvarelser fortsetter på neste side. Tekst og bilder er direkte PDF-utsnitt, uten omskriving. Originalvedlegget til oppgave 31, kontinuasjon våren 2015, er tomt i kildematerialet; dette er merket i dokumentet.

## Tidligere versjon og komplette sett

- [Histologioppgaver med originale sensorveiledninger (PDF, ca. 40 MB)](dokumenter/Histologi_oppgaver_og_sensorveiledninger.pdf)
- [30 komplette eksamenssett (ZIP, ca. 63 MB)](dokumenter/Komplette_eksamenssett.zip)
- [Oversikt og kontroll](dokumenter/Oversikt_og_kontroll.md)

Den tidligere PDF-en med hele originalsider inneholder 250 sider, organisert etter eksamenssett, med oversikt og bokmerker. De 217 kopierte originalsidene er kontrollert mot kilden for identisk tekst, sidestørrelse og visuell gjengivelse. Sensorveiledningene er ikke skrevet om. Hele originalsider er beholdt, slik at enkelte nabooppgaver følger med.

For nedlasting: åpne filen og velg **Download raw file** (nedlastingsikonet). GitHub kan unnlate å vise forhåndsvisning av store PDF-er; filen kan likevel lastes ned.
