# Eksamensmateriale – histologi

- [Histologioppgaver med originale sensorveiledninger (PDF, ca. 40 MB)](dokumenter/Histologi_oppgaver_og_sensorveiledninger.pdf)
- [30 komplette eksamenssett (ZIP, ca. 63 MB)](dokumenter/Komplette_eksamenssett.zip)
- [Oversikt og kontroll](dokumenter/Oversikt_og_kontroll.md)

PDF-en inneholder 250 sider, organisert etter eksamenssett, med oversikt og bokmerker. De 217 kopierte originalsidene er kontrollert mot kilden for identisk tekst, sidestørrelse og visuell gjengivelse. Sensorveiledningene er ikke skrevet om. Hele originalsider er beholdt, slik at enkelte nabooppgaver følger med.

For nedlasting: åpne filen og velg **Download raw file** (nedlastingsikonet). GitHub kan unnlate å vise forhåndsvisning av store PDF-er; filen kan likevel lastes ned.
